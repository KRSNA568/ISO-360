Build an end-to-end web exam portal for the TPRM Course with user registration & verification, two timed certification exams (Beginner & Professional), a secure question-bank mechanism, automatic certificate generation (.jpeg) on pass, and share/download UX optimized for LinkedIn. The certificates must state the exam is free and be “2026 premium” design quality.

Powered by: Learntprm.com

1. Key user flows
1.1 Registration → Verification → Login

User provides: full_name, email, phone, city, company_name (optional), role (optional), country.

On submit: send email OTP . Require email verification.

After verification create account and show a “Take Exam” dashboard.

1.2 Exam purchase/enrolment

These are free exams. On exam page show exam details, passing score, time limit, sample question, and CTA “Enroll — Free”.

Before enrollment show a one-line notice: “Passing marks: 40/50. This certification is free from Learntprm.com.”

1.3 Take Exam

Two exams available:

Certified TPRM Warrior — Beginner (50 questions, 10 minutes total)

Certified TPRM Warrior — Professional (50 questions, 10 minutes total)

Per question rules:

15-second per-question countdown. If no answer in 15s, automatically advance (mark as unanswered/wrong).

Once an answer is selected it is final for that question (no going back).

Selecting an option does NOT reset the 15s question timer nor the overall 10-minute exam timer.

Show overall exam timer (10:00) and per-question timer (15s).

After last question or timer expiry, submit and show result page.

2. Question bank & exam generation logic (backend)
2.1 Pools

Beginner pool: 100 questions.

Professional pool: 100 questions (sourced from interviews, prior exams, advanced materials).

Each question object: ID, stem, options (A–D), single correct option, explanation for correct & why other options are wrong, tags, difficulty, last-updated timestamp, source citation.

2.2 Selecting 50 questions per attempt

Randomly sample 50 unique questions from the 100 pool for each attempt.

Overlap rule (assumption / implementation suggestion): to reduce repeated exposure for the same user, ensure that for the same user’s consecutive attempts at the same level, no more than 3 identical questions are reused. (This requires storing the last attempt question IDs per user.)

If you want global uniqueness between any two attempts by different users, that’s impractical; the proposed constraint applies per-user.

Shuffle order of the chosen 50 questions for the attempt.

2.3 Question rotation frequency

Allow admins to set rotation/difficulty weights (for future). By default, rotate randomly; allow an audit endpoint to see how many times a question has been used.

3. Timers & client behavior (important)

Two timers: global_timer = 600s and question_timer = 15s.

UI must show both prominently.

Client must persist state every 5–10s to server (or at least cursor position + current question + remaining times) to support network failures.

Prevent going back:

Disable previous question buttons.

On navigation away or refresh: show warning (“Your exam progress will be submitted”).

On answer click:

Record answer + timestamp (millisecond precision)

Do not restart per-question timer; proceed as usual.

If network disconnects: allow local caching of answers and auto-sync when network is back; but overall timers continue (no freeze).

4. Scoring & result presentation

Score: integer 0–50.

Passing threshold: 40/50. This must be stated on exam landing BEFORE enrollment.

Result page:

Score (e.g., 43/50)

Pass / Fail banner

Correct answer

Short explanation why correct & why wrong (from question object)

Note: “This is a free certification from Learntprm.com” in results.

If score >= 40: show “Download Certificate” button (see next section).

7. Admin & content management

Admin dashboard to:

Upload/edit questions with explanation, source, tags.

Bulk import via CSV/Excel (validate duplicates).

Review usage stats per question (times served, average correctness).

Force-rotate questions or retire old ones.

Audit logs: record every exam attempt, timestamps, IP, user agent for fraud detection.

8. Security & anti-cheat recommendations

Rate-limit attempts per user (e.g., max 3 attempts per 24 hours) — configurable.

Detect suspicious patterns: extremely short total time with perfect score, same IP mass attempts, multiple accounts from same device.

Device/browser fingerprinting and IP logging for fraud investigations.

Proctoring options (optional): webcam snapshot at start + random snapshots (consent needed).

Prevent copy/paste (UI level) and disable right-click on question page (defense in depth, not foolproof).

9. Performance, accessibility, and mobile

Page must be responsive (mobile-first). Per-question UI should be thumb-friendly.

Accessibility: WCAG AA (contrast, alt text, keyboard navigation). Timers must be perceivable by screen readers.

Offline/resume policy: if the user reloads, attempt to resume but continue timers (do not freeze). Save state server-side frequently.
